IPv6 Addressing Explained

Internet Protocol version 6 (IPv6) is the successor to IPv4. It was developed to address the limitations of IPv4, particularly the shortage of globally unique IPv4 addresses.

IPv6 uses 128-bit addresses, compared with the 32-bit addresses used by IPv4.

1. Why Was IPv6 Introduced?

IPv4 has several limitations:

  • Limited address space.
  • Increasing demand for internet-connected devices.
  • Greater reliance on address translation techniques.
  • Need for improvements in network-layer functionality.

IPv6 provides a much larger address space and supports features such as stateless address autoconfiguration.

2. IPv4 vs IPv6

Feature IPv4 IPv6
Address size 32 bits 128 bits
Notation Decimal Hexadecimal
Address example 192.168.1.1 2001:db8::1
Broadcast Supported Not used
Address resolution ARP Neighbor Discovery Protocol
Header checksum Present Not present

3. IPv6 Address Structure

An IPv6 address consists of 128 bits, divided into eight groups of 16 bits.

Example:

2001:0DB8:0000:0000:0000:0000:0000:0001

Each group contains four hexadecimal digits and is separated by a colon.

4. IPv6 Address Compression

IPv6 supports two important rules that make addresses easier to write.

Rule 1: Remove Leading Zeros

Leading zeros within an individual group can be omitted. 

2001:0DB8:0000:0000:0000:0000:0000:0001

Becomes:

2001:DB8:0:0:0:0:0:1

Rule 2: Replace Consecutive Zero Groups

One consecutive sequence of all-zero groups can be replaced with a double colon (::). 

2001:DB8:0:0:0:0:0:1

Becomes:

2001:DB8::1
Important: The double-colon notation can appear only once in an IPv6 address. Using it more than once would make the original number of zero groups ambiguous.

5. Types of IPv6 Addresses

Global Unicast Address

Global Unicast Addresses are globally routable IPv6 addresses. They are generally allocated from the 2000::/3 address space.

Example:

2001:DB8:100::10/64

The documentation prefix 2001:DB8::/32 is reserved for examples and documentation, not normal public deployment.

Link-Local Address

Link-local addresses are used for communication within a local network link. They are not routed between links. 

FE80::/10

Unique Local Address

Unique Local Addresses are intended for private internal communication and are not globally routed on the public internet. 

FC00::/7

Multicast Address

Multicast addresses identify a group of interfaces. A packet sent to a multicast address is delivered to participating members of that group. 

FF00::/8

6. SLAAC (Stateless Address Autoconfiguration)

SLAAC allows IPv6 devices to configure their own addresses using information advertised by routers.

  1. The router sends Router Advertisement messages.
  2. The advertisement provides network prefix information.
  3. The host forms an IPv6 address using the prefix and an interface identifier.
  4. The host performs Duplicate Address Detection.

SLAAC reduces the need for manual IPv6 address configuration.

7. DHCPv6

DHCPv6 is a protocol that provides IPv6 configuration information to network devices.

There are two common approaches:

  • Stateful DHCPv6: The DHCPv6 server assigns IPv6 addresses and maintains allocation information.
  • Stateless DHCPv6: Hosts obtain addresses through SLAAC and use DHCPv6 for additional configuration information.

8. Cisco IPv6 Configuration

Enable IPv6 Routing

enable
configure terminal

ipv6 unicast-routing

Configure an IPv6 Interface

interface gigabitEthernet 0/0

ipv6 address 2001:DB8:10::1/64

no shutdown

exit

Configure a Link-Local Address Manually

interface gigabitEthernet 0/0

ipv6 address FE80::1 link-local

exit

9. IPv6 Verification Commands

show ipv6 interface brief

show ipv6 neighbors

ping 2001:DB8:10::2

10. Common IPv6 Troubleshooting Problems

  • Incorrect IPv6 address or prefix length.
  • Interface administratively shut down.
  • Missing IPv6 routing configuration.
  • Incorrect default gateway or router advertisement configuration.
  • Duplicate IPv6 address.
  • Neighbor Discovery problems.
  • Incorrect routing information.

11. Practical Packet Tracer Lab

Build a small IPv6 network containing:

  • Two routers.
  • Two switches.
  • Two PCs connected to separate networks.

Complete these tasks:

  1. Assign IPv6 addresses to router interfaces.
  2. Enable IPv6 routing.
  3. Configure IPv6 routing between the routers.
  4. Configure IPv6 addresses on both PCs.
  5. Test connectivity using ping.
  6. Inspect IPv6 routing and neighbor tables.

Conclusion

IPv6 provides a significantly larger address space than IPv4 and introduces features that support modern IP networks. Understanding address structure, address types, SLAAC, DHCPv6 and routing is essential for network engineers.
