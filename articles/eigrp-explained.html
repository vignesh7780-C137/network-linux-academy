EIGRP Explained: Enhanced Interior Gateway Routing Protocol

EIGRP (Enhanced Interior Gateway Routing Protocol) is a dynamic routing protocol developed by Cisco. It allows routers to exchange routing information and automatically select the best paths through an IP network.

EIGRP is commonly described as an advanced distance-vector routing protocol. It uses the Diffusing Update Algorithm (DUAL) to calculate loop-free routes and provide fast convergence.

1. What Is EIGRP?

EIGRP enables routers to discover neighboring routers, exchange routing information, and maintain routes to remote networks.

Important characteristics include:

  • Advanced distance-vector routing protocol.
  • Uses the DUAL algorithm.
  • Supports classless routing and VLSM.
  • Supports route summarization.
  • Uses partial and bounded updates.
  • Supports equal-cost and unequal-cost load balancing.
  • Uses multicast address 224.0.0.10 for IPv4 updates.

2. How EIGRP Works

EIGRP routers discover neighbors and establish relationships before exchanging routing information.

The basic process is:

  1. Routers send EIGRP Hello packets.
  2. Neighbor relationships are established.
  3. Routers exchange routing information.
  4. DUAL calculates loop-free paths.
  5. Best routes are installed in the routing table.

3. EIGRP Autonomous System Number

EIGRP uses an Autonomous System (AS) number to identify an EIGRP routing process. Routers must use the same AS number to become neighbors through that EIGRP process.

Example:

Router(config)# router eigrp 100

Here, 100 is the EIGRP autonomous system number.

4. EIGRP Neighbor Relationships

EIGRP routers discover one another using Hello packets. These packets are sent periodically to identify neighboring routers and maintain neighbor relationships.

For two routers to become EIGRP neighbors, important requirements include:

  • They must have compatible EIGRP AS configuration.
  • They must share a compatible IP subnet on the connecting interface.
  • Authentication settings must match, if configured.
  • K-values must match.
  • EIGRP must be enabled on the connecting interfaces.

A router's EIGRP neighbor information can be viewed using: 

Router# show ip eigrp neighbors

5. DUAL Algorithm

DUAL stands for Diffusing Update Algorithm. It is the algorithm EIGRP uses to calculate loop-free paths and determine which routes can be used as alternatives.

DUAL helps EIGRP achieve fast convergence without relying on periodic full routing-table updates.

6. Successor and Feasible Successor

Successor

The successor is the best next-hop router for reaching a destination. Its route is normally installed in the routing table.

Feasible Successor

A feasible successor is a backup next-hop route that satisfies EIGRP's feasibility condition. It can provide an alternative path if the successor route fails.

Feasibility Condition

A neighbor's Reported Distance (RD) must be lower than the local router's Feasible Distance (FD) for that neighbor to qualify as a feasible successor. 

Reported Distance < Feasible Distance

This condition helps ensure that the alternative path is loop-free.

7. EIGRP Metric

EIGRP calculates route metrics using multiple parameters. By default, bandwidth and delay are used in the metric calculation.

Other available metric parameters include:

  • Bandwidth
  • Delay
  • Reliability
  • Load
  • MTU (not included in the default metric calculation)

EIGRP uses K-values to determine the contribution of metric parameters. Its default K-values prioritize bandwidth and delay.

8. EIGRP Packet Types

Packet Purpose
Hello Discover and maintain neighbors.
Update Exchange routing information.
Query Ask neighbors for routing information.
Reply Respond to a query.
Acknowledgment Reliably acknowledge certain EIGRP packets.

9. Configuring EIGRP on Cisco Routers

Consider a simple topology with three routers connected in a line: 


R1 -------- R2 -------- R3

R1 LAN: 192.168.1.0/24
R2 LAN: 192.168.2.0/24
R3 LAN: 192.168.3.0/24

R1-R2: 10.0.12.0/30
R2-R3: 10.0.23.0/30

R1 Configuration

enable
configure terminal

router eigrp 100
 network 192.168.1.0 0.0.0.255
 network 10.0.12.0 0.0.0.3
 no auto-summary

end
write memory

R2 Configuration

enable
configure terminal

router eigrp 100
 network 192.168.2.0 0.0.0.255
 network 10.0.12.0 0.0.0.3
 network 10.0.23.0 0.0.0.3
 no auto-summary

end
write memory

R3 Configuration

enable
configure terminal

router eigrp 100
 network 192.168.3.0 0.0.0.255
 network 10.0.23.0 0.0.0.3
 no auto-summary

end
write memory

These are classic EIGRP configuration examples. The network statements enable EIGRP on matching interfaces and advertise their connected networks.

10. EIGRP Verification Commands

Use these commands to inspect EIGRP operation:

show ip eigrp neighbors
show ip eigrp topology
show ip route eigrp
show ip protocols
show ip eigrp interfaces
show ip eigrp traffic

Routes learned through EIGRP are marked with the letter D in the Cisco IPv4 routing table.

11. EIGRP Troubleshooting

Common problems include:

Problem Possible Cause
No neighbors AS mismatch, interface issue, subnet mismatch or incompatible K-values.
Missing routes Incorrect network statements or routing configuration.
Unstable adjacency Unreliable link, packet loss or configuration mismatch.
Unexpected path selection Different bandwidth or delay values affecting metrics.

12. Practical Packet Tracer Lab

Build a network containing three Cisco routers.

  1. Connect R1 to R2 and R2 to R3.
  2. Assign IP addresses to all router interfaces.
  3. Configure a separate LAN behind each router.
  4. Configure EIGRP using AS number 100.
  5. Verify that all three routers become neighbors where directly connected.
  6. Check the routing tables.
  7. Ping between PCs on different LANs.
  8. Disconnect a link and observe how EIGRP reacts.

13. Key Takeaways

  • EIGRP is an advanced distance-vector routing protocol.
  • DUAL calculates loop-free routes.
  • The successor is the best route.
  • A feasible successor is a qualifying backup route.
  • EIGRP uses Hello packets to discover neighbors.
  • Bandwidth and delay are used in its default metric.
  • The default IPv4 EIGRP multicast address is 224.0.0.10.

Conclusion

EIGRP is an important dynamic routing protocol to understand when studying enterprise networking and Cisco routing. Learning its neighbor relationships, DUAL algorithm, metrics and troubleshooting commands provides a strong foundation for practical routing labs.
