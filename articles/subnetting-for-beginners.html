1. What Is Subnetting?

Subnetting is the process of dividing a larger IP network into smaller logical networks called subnets. Each subnet has its own network address and address range.

Instead of placing every device inside one large network, an administrator can divide devices into smaller groups. For example, a company might create separate subnets for its administration, finance, engineering, and guest networks.

Remember: Subnetting divides an IP network into smaller networks. It does not physically divide the network cables or devices.

2. Why Do We Need Subnetting?

Subnetting provides several practical benefits:

  • Better organization: Devices can be grouped by department, function, or location.
  • Smaller broadcast domains: Routers separate broadcast traffic between different IP subnets.
  • Efficient address allocation: Networks can receive address ranges appropriate to their size.
  • Network management: Administrators can apply routing and security policies between subnets.
  • Scalability: A network can grow without placing every device in one enormous subnet.

3. Understanding IPv4 and Binary

An IPv4 address is 32 bits long. It is written as four decimal numbers called octets, separated by dots.

Example IPv4 address

192.168.1.10

Each octet represents 8 bits.

19211000000
16810101000
100000001
1000001010

Total: 4 × 8 = 32 bits.

Binary place values

Each 8-bit octet uses these place values:

128643216 8421

For example, the binary number 11000000 represents 128 + 64 = 192.

4. What Is a Subnet Mask?

A subnet mask identifies which bits of an IPv4 address represent the network portion and which bits represent the host portion.

In a standard IPv4 subnet mask, network bits are set to 1 and host bits are set to 0.

Example: 255.255.255.0

Decimal mask: 255.255.255.0

Binary mask:

11111111.11111111.11111111.00000000

The first 24 bits represent the network portion. The remaining 8 bits represent the host portion.

The subnet mask helps a device determine whether a destination IPv4 address is on its local network or needs to be reached through a router.

5. Understanding CIDR Notation

CIDR stands for Classless Inter-Domain Routing. CIDR notation represents the number of network bits using a slash followed by a number.

Example: 192.168.1.0/24

The /24 means that 24 bits are used for the network portion.

That leaves 32 − 24 = 8 host bits.

Subnet mask: 255.255.255.0

Here are some common CIDR prefixes:

  • /8 — 255.0.0.0
  • /16 — 255.255.0.0
  • /24 — 255.255.255.0
  • /25 — 255.255.255.128
  • /26 — 255.255.255.192
  • /27 — 255.255.255.224
  • /28 — 255.255.255.240

6. The Four Important Subnet Calculations

6.1 Number of host bits

Subtract the CIDR prefix from 32:

Host bits = 32 − prefix length

6.2 Total number of addresses

Raise 2 to the power of the number of host bits:

Total addresses = 2host bits

6.3 Usable host addresses

For a conventional IPv4 subnet with at least two host bits, the network and broadcast addresses are not assigned to ordinary hosts.

Usable hosts = 2host bits − 2

Special cases exist, including /31 point-to-point links and /32 host routes.

6.4 Block size

When the subnet mask changes within an octet, calculate the block size using:

Block size = 256 − interesting octet value

For example, a /26 mask is 255.255.255.192. The block size is 256 − 192 = 64.

7. Worked Example: 192.168.1.0/26

Let's calculate the network address, broadcast address, and usable host range for:

192.168.1.0/26

Step 1: Find the subnet mask

A /26 prefix means 26 network bits and 6 host bits.

Subnet mask: 255.255.255.192

Step 2: Calculate the total addresses

There are 6 host bits:

26 = 64 addresses

Step 3: Calculate usable hosts

64 − 2 = 62 usable host addresses

Step 4: Calculate the block size

256 − 192 = 64

Step 5: Identify the address range

The subnet ranges in the final octet increase in blocks of 64:

  • First subnet: 192.168.1.0 – 192.168.1.63
  • Second subnet: 192.168.1.64 – 192.168.1.127
  • Third subnet: 192.168.1.128 – 192.168.1.191
  • Fourth subnet: 192.168.1.192 – 192.168.1.255

First subnet result

Network address: 192.168.1.0

First usable address: 192.168.1.1

Last usable address: 192.168.1.62

Broadcast address: 192.168.1.63

Total addresses: 64

Usable hosts: 62

9. Introduction to VLSM

VLSM stands for Variable Length Subnet Masking. It allows different subnets within the same address space to use different prefix lengths.

Imagine a company needs three networks:

  • Network A: 100 host addresses
  • Network B: 50 host addresses
  • Network C: 20 host addresses

Giving every network a /24 would allocate 256 addresses to each subnet, even when many addresses are unnecessary. VLSM allows the administrator to select appropriately sized subnets for each requirement.

Important: Allocate the largest required subnet first when planning a VLSM address allocation. Then allocate smaller subnets from the remaining space, ensuring that subnet ranges do not overlap.

11. Frequently Asked Questions

What is the difference between an IP address and a subnet mask?

An IP address identifies a network interface at the IPv4 layer. A subnet mask identifies the network and host portions of the address.

What does /24 mean?

It means the first 24 bits are network bits, leaving 8 bits for host addressing.

Can two devices in different subnets communicate?

Yes. They generally communicate through a router or another Layer 3 device that can route traffic between their networks.

Is subnetting important for CCNA?

Yes. Subnetting is a core networking skill used in IPv4 addressing, routing, network design, and troubleshooting.

Conclusion

Subnetting is one of the most important skills in IPv4 networking. Once you understand binary, subnet masks, CIDR prefixes, and block sizes, you can calculate subnet ranges systematically rather than memorizing answers.

Practice with different prefixes and address ranges until the calculations become familiar. Then move on to VLSM and practical subnetting exercises.
